# Debate Timer (Web)

Plain HTML, CSS and JavaScript with no build step: `index.html`, `styles.css`, `app.js`. GitHub Pages serves
`main` at https://michaelihc.github.io/debate-timer-web/, so merging to `main` deploys.

## Never remove settings

- Never remove a setting or the behaviour it controls, including during rewrites, ports and redesigns.
- If the settings panel gets cluttered, move a setting to a less prominent place (the Advanced page, a part's own
  settings dialog, or a collapsed section) instead of deleting it.
- Saves and preset files from earlier versions must keep loading with the same meaning. New fields are optional, with
  defaults that keep the existing behaviour.
- When porting or rewriting, list every setting of the old version first and check each one exists in the new one.
